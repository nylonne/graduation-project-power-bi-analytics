# Design Reference

The supplied Figma export is stored at:

`assets/design/figma-dashboard-reference.svg`

It is the visual reference for future dashboard layouts, documentation previews, and project presentation material. The export is retained as an SVG so it stays crisp and inspectable at any display size.

## Use in the project

- Preserve this file as the approved reference for the supplied 1280 × 720 design.
- Use it to guide visual consistency when creating or revising report pages, exported material, or documentation images.
- Keep report logic, data transformations, and model structure independent of visual styling changes.
- Do not replace the reference or claim ownership of its design elements without group approval.
